1. DISTINCTION BETWEEN GIT BLOB IDS AND SHA-256 DIGESTS
--------------------------------------------------------------------------------
To eliminate potential confusion between version-control objects and cryptographic file hashes:
- Git Blob ID: A 40-character SHA-1 hash computed over `blob <size>\0<content>`. It identifies
  the object within Git's internal content-addressable database.
- File SHA-256: A 64-character SHA-256 digest computed strictly over the raw binary bytes
  of the file content alone.
