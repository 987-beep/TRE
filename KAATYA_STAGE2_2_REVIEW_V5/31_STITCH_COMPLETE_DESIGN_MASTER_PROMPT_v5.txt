--------------------------------------------------------------------------------

- Primary Reference Resolution: 1366 x 768 Landscape (Reference Baseline).
- Viewport Adaptation: The interface must NOT be hardcoded as an immutable fixed box;
  it must fluidly adapt to 1366x768, 1920x1080 (FHD), 2560x1440 (2K), and 4K displays.

  * Floating windows support free resizing with a minimum geometry of 640x480.
  * Window Snapping: Half-screen (50% split), Quarter-screen (25% corner snap), Fullscreen.

- Multi-Monitor Support: Secondary displays feature an independent, auto-dimming taskbar.
- Taskbar Geometry: Docked at bottom edge (48px height on reference display, 56px on Hi-DPI).

- Contrast Ratios: WCAG 2.1 AA compliance (minimum 4.5:1 text-to-background contrast).
- Accessibility Semantics:
  * Native Qt6 / Linux Applications: Map explicitly to Linux AT-SPI2 accessibility roles.
  * Web / PWA Content: Map to W3C WAI-ARIA roles (`role="dialog"`, `aria-live="assertive"`).
- Keyboard Navigation: Full focus ring (`2px solid var(--accent-primary)`) navigable via
  `Tab`, `Shift+Tab`, `Arrow Keys`, `Enter`, and `Escape`.
- Reduced Motion Mode: Replaces scale/slide/particle transitions with a clean 80ms cross-fade.
- Text & Display Scaling: Fractional scaling (1.0x, 1.25x, 1.5x) with integer pixel rounding.
