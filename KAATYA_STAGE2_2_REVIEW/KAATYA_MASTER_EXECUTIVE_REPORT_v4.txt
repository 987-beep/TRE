1. EXECUTIVE SYSTEM DEFINITION
--------------------------------------------------------------------------------
KAATYA OS 3.0 is a complete, original, AI-native desktop operating system. It merges
the stability and security of Debian 13 LTS Linux, the hardware-accelerated fluid
responsiveness of a custom Qt 6 / QML desktop shell on an established KWin-Wayland compositor,
an uncompromised local-first AI system architecture, universal multi-runtime application
compatibility, and an original supernatural anime visual aesthetic.

2. AUTHORITATIVE RECONCILED ARCHITECTURAL DECISIONS
--------------------------------------------------------------------------------
1. OS Foundation & Compositor:
   - Base: Debian 13 "Trixie" LTS.
   - Kernel: Standard Debian 13 kernel (`linux-image-amd64`) for initial prototype.
   - Compositor: Established KWin-Wayland wrapper (ensures rock-solid stability and Xwayland).
   - Default Filesystem: Ext4 default for initial prototype; Btrfs evaluated for rollback.
2. Local & Cloud Intelligence (`kaatya-aid`):
   - Local Inference: `llama.cpp` AVX2. Default local LLM is `Qwen3-4B-Q4_K_M.gguf`.
   - Nemotron 3.5 Bolt (Gemma4-based, 7.5B metadata label): On-demand specialist model.
   - Concurrency Rule: Strictly MAX 1 LLM loaded in RAM at any time; never load both concurrently.
   - Local Semantic Memory: `sqlite-vec` (embedded C vector engine) designated as PRIMARY.
   - Voice Engine: Whisper.cpp (`ggml-base.bin`) STT + Piper ONNX (English `mike` & Hindi `rohan`).
   - Cloud Providers: 10 commercial cloud APIs + 4 local adapters behind an AES-GCM credential vault.
3. Application Ecosystem:
   - Native: Qt 6 / C++20 core applications suite.
   - Android APKs: Waydroid LXC container (honest appraisal: GMS not bundled; F-Droid/Aurora Store used).
   - Windows EXEs: Wine 9.x / Bottles prefixes (Win32/PE supported; UWP/Store apps require Windows VM).
   - Browser: Chromium-based KAATYA Browser with VA-API hardware decoding and AI side-panel.
4. Visual Design & Customization:

     Cursed Energy, Obsidian Cyan, Clean Studio.
