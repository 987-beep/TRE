2. CRITICAL ARCHITECTURAL CONCURRENCY & ISOLATION RULES
--------------------------------------------------------------------------------
1. Rule of One Active LLM: At any point in time, strictly ONE large language model
   may be loaded into memory. Loading Nemotron 7.5B automatically evicts Qwen3-4B.
2. Embedded Vector Storage: Memory is embedded directly in SQLite via `sqlite-vec`.
   No standalone database server daemon is permitted to consume background RAM.
3. Unprivileged Execution: All third-party Android APKs and Windows executables
   are jailed via Bubblewrap namespaces (`bwrap`) with read-only root mounts.
