1. FORMULA DERIVATION BASED ON VERIFIED B8665 SOURCE MAPPING
--------------------------------------------------------------------------------
From verified historical source mapping (4 independent Global layers, 20 independent SWA layers):

1. Global Attention KV Cache Rate:
   - Independent Global Layers: Exactly 4 layers (Indices 5, 11, 17, 23).
   - KV Heads: 2 heads.
   - Head Key Dimension: 512 elements.
   - Head Value Dimension: 512 elements.
   - Precision: FP16 (2 Bytes per element).
   - K bytes/token/layer: 2 heads * 512 dim * 2 Bytes = 2,048 Bytes.
   - V bytes/token/layer: 2 heads * 512 dim * 2 Bytes = 2,048 Bytes.
   - Rate per Global layer: 2,048 B (K) + 2,048 B (V) = 4,096 Bytes/token.
   - Total Global Rate: 4 layers * 4,096 Bytes/token = 16,384 Bytes/token.

2. Sliding Window Attention (SWA) Cache Footprint:
   - Independent SWA Layers: Exactly 20 layers.
   - KV Heads: 2 heads.
   - Head Key Dimension: 256 elements.
   - Head Value Dimension: 256 elements.
   - Precision: FP16 (2 Bytes per element).
   - Rate per SWA layer: 2 heads * 256 dim * 2 Bytes * 2 (K+V) = 2,048 Bytes/token.
   - SWA Window Size (W): 512 tokens (circular ring buffer).
   - Capacity per independent SWA layer: 2,048 Bytes/token * 512 tokens = 1,048,576 Bytes (1.00 MiB).
   - Total SWA Ring Buffer Footprint: 20 layers * 1,048,576 Bytes = 20,971,520 Bytes (20.00 MiB).

3. Shared Layer Contribution:
   - 3 shared Global layers + 15 shared SWA layers = 18 shared layers.
   - These 18 layers alias existing cache pages established by layers 22 and 23.
   - Additional allocation: Exactly 0 Bytes.
