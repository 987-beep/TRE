3. THEORETICAL PAYLOAD VS ALLOCATED RUNTIME RAM
================================================================================
CRITICAL DISTINCTION MANDATED BY QUALITY GATE:
The values calculated above represent THEORETICAL KV PAYLOAD bytes.
Theoretical payload MUST NOT be conflated with measured runtime RAM or allocated memory:
1. Theoretical KV Payload: Exact sum of active FP16 Key and Value tensor elements.
2. Allocated GGML Buffers: GGML allocates memory in page-aligned contiguous buffers (e.g., 64-byte 
   alignment or 2 MiB / 4 KiB virtual page boundaries), introducing internal fragmentation.
3. Virtual Address Space: The operating system reserves contiguous virtual memory address ranges 
   that exceed committed memory.
4. Committed Memory: Memory backed by physical RAM or pagefile allocated by the OS allocator.
5. Resident Physical RAM (Working Set): The actual physical memory pages currently resident in RAM.
CONCLUSION:
Theoretical payload (148 MiB at 8K, 532 MiB at 32K) establishes the absolute mathematical floor. 
Actual resident RAM will be higher due to GGML buffer alignment, scratch buffers, activation memory, 
and OS paging overhead. Runtime RAM must be measured empirically when Stage 3 is unlocked.
